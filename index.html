🎮 Roteiro Prático: Construção do Jogo Genius (Tinkercad)

Aprenda a montar e programar um jogo de memória eletrônico utilizando Arduino, LEDs e Botões.

1. 🛠️ Etapa 1: Teste dos Primeiros Componentes

Na primeira etapa, montamos metade do circuito para validar as conexões do LED Amarelo e LED Vermelho com seus respectivos botões.

Cor Componente Pino Digital (Arduino) Modo no Código
Amarelo LED / Botão Pino 2 (LED) / Pino 8 (Botão) OUTPUT / INPUT_PULLUP
Vermelho LED / Botão Pino 3 (LED) / Pino 9 (Botão) OUTPUT / INPUT_PULLUP

2. 🚀 Etapa 2: O Desafio de Expansão (4 Cores)

🎯 Seu Objetivo:

Agora que os dois primeiros botões estão funcionando, seu desafio é completar a montagem física no Tinkercad e atualizar o código C++ para incluir os componentes Verde e Azul.

📋 Tabela Geral de Mapeamento dos Pinos:

Cor Pino do LED Pino do Botão Status

Vermelho Pino 3 Pino 9 ✅ Montado (Etapa 1)
Verde Pino 4 Pino 10 ✏️ Sua vez de montar!
Azul Pino 5 Pino 11 ✏️ Sua vez de montar!

3. 💻 Passo a Passo da Programação

Siga os passos abaixo na aba de código do Tinkercad para completar a lógica:

  1. Declare os novos pinos: Crie as variáveis ledVerde, ledAzul, botaoVerde e botaoAzul com os pinos indicados na tabela.
  2. Configure no setup(): Adicione o pinMode() dos novos LEDs como OUTPUT e dos novos botões como INPUT_PULLUP.
  3. Adicione o acionamento no loop(): Escreva os blocos if (digitalRead(...) == LOW) para acionar a função piscarLed() das novas cores.
Código Modelo para Completar (C++)
// --- DECLARAÇÃO DOS PINOS ---
const int ledAmarelo = 2;
const int ledVermelho = 3;
// ✏️ COMPLETE AQUI: Declare ledVerde (Pino 4) e ledAzul (Pino 5)

const int botaoAmarelo = 8;
const int botaoVermelho = 9;
// ✏️ COMPLETE AQUI: Declare botaoVerde (Pino 10) e botaoAzul (Pino 11)

void setup() {
  pinMode(ledAmarelo, OUTPUT);
  pinMode(ledVermelho, OUTPUT);
  // ✏️ COMPLETE AQUI: Configure os LEDs Verde e Azul como OUTPUT

  pinMode(botaoAmarelo, INPUT_PULLUP);
  pinMode(botaoVermelho, INPUT_PULLUP);
  // ✏️ COMPLETE AQUI: Configure os Botões Verde e Azul como INPUT_PULLUP
}

void piscarLed(int pinoLed) {
  digitalWrite(pinoLed, HIGH);
  delay(300);
  digitalWrite(pinoLed, LOW);
  delay(100);
}

void loop() {
  // Verificação dos botões da Etapa 1
  if (digitalRead(botaoAmarelo) == LOW) {
    piscarLed(ledAmarelo);
  }
  if (digitalRead(botaoVermelho) == LOW) {
    piscarLed(ledVermelho);
  }

  // ✏️ COMPLETE AQUI: Adicione os testes para o botaoVerde e botaoAzul
}
